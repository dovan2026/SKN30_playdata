# 개발 환경 준비

## 1. 개발 환경 준비 가이드

본 과정의 실습은 Windows 11 환경에서 Python 실행 환경과 IDE를 설정해야 합니다. 여기서는 **uv**, **uv 가상환경(.venv)**, 그리고 **VS Code**를 활용하여 CrewAI 실습에 필요한 개발 환경을 구축하는 방법을 설명합니다.

uv는 Python 버전 관리, 가상환경 생성, 패키지 설치를 빠르게 처리할 수 있는 도구입니다. 별도의 Python 배포판을 설치하지 않아도 프로젝트별 독립 환경을 만들 수 있습니다.

## 2. uv 설치

PowerShell을 열고 아래 명령을 실행합니다.

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

설치가 끝나면 PowerShell 또는 VS Code 터미널을 새로 열고 설치 여부를 확인합니다.

```powershell
uv --version
```

버전이 출력되면 uv 설치가 완료된 것입니다. 만약 `uv` 명령을 찾을 수 없다는 메시지가 나오면 터미널을 완전히 닫았다가 다시 열어보세요.

## 3. 프로젝트 폴더로 이동

VS Code에서 이 강의 폴더를 열었거나, PowerShell에서 프로젝트 루트 폴더로 이동한 상태라고 가정합니다.

예시:

```powershell
cd "C:\workspace\crewai"
```

이 위치에서 `.venv` 가상환경을 만들면 VS Code가 해당 환경을 쉽게 인식할 수 있습니다.

## 4. Python 3.13용 uv 가상환경 생성

CrewAI 실습에서는 Python 3.13 사용을 권장합니다. 프로젝트 루트 폴더에서 아래 명령을 실행합니다.

```powershell
uv venv --python 3.13
```

명령이 완료되면 프로젝트 폴더에 `.venv` 디렉터리가 생성됩니다. 이 폴더가 현재 프로젝트 전용 Python 가상환경입니다.

uv가 로컬에 Python 3.13를 찾지 못하면 필요한 Python을 자동으로 내려받아 환경을 만들 수 있습니다.

## 5. 가상환경 활성화

PowerShell에서 아래 명령으로 가상환경을 활성화합니다.

```powershell
.venv\Scripts\activate
```

활성화되면 터미널 프롬프트 앞에 `(.venv)`가 표시됩니다. 이 상태에서 Python 버전을 확인합니다.

```powershell
python --version
```

`Python 3.13.x` 형태로 출력되면 정상입니다.

만약 PowerShell 실행 정책 때문에 활성화가 막히면 아래 명령을 한 번 실행한 뒤 터미널을 다시 열어 활성화합니다.

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

## 6. CrewAI 실습 패키지 설치

가상환경이 활성화된 상태에서 CrewAI와 노트북 실행에 필요한 패키지를 설치합니다.

```powershell
uv pip install -U python-dotenv notebook ipykernel "crewai[tools]"
```

설치가 끝나면 CrewAI가 정상 import 되는지 확인합니다.

```powershell
python -c "from crewai import Agent, Task, Crew, Process, LLM; print('CrewAI import OK')"
```

정상이라면 `CrewAI import OK`가 출력됩니다.

## 7. Jupyter 커널 등록

VS Code 노트북에서 `.venv` 환경을 명확히 선택할 수 있도록 Jupyter 커널을 등록합니다.

```powershell
python -m ipykernel install --user --name crewai_basic --display-name "crewai_basic"
```

이후 `.ipynb` 파일을 열고 오른쪽 위의 커널 선택 메뉴에서 **crewai_basic** 또는 `.venv` Python 환경을 선택합니다.

## 8. VS Code 설치 및 필수 확장팩 설치

개발을 편리하게 진행하려면 **Visual Studio Code**를 설치하는 것이 좋습니다.

- **VS Code 다운로드:** [VS Code 공식 사이트](https://code.visualstudio.com/)에서 Windows용 설치 파일을 받아 설치합니다.
- **한글 언어 팩 설치:** 확장 탭에서 `Korean Language Pack for Visual Studio Code`를 검색해 설치합니다.
- **Python 확장 설치:** Microsoft의 `Python` 확장을 설치합니다.
- **Jupyter 확장 설치:** VS Code에서 `.ipynb` 노트북을 실행하기 위해 `Jupyter` 확장을 설치합니다.

## 9. VS Code에서 uv 가상환경 연동 방법

앞서 생성한 `.venv` 가상환경을 VS Code에 연결합니다.

1. VS Code에서 `Ctrl+Shift+P`를 누릅니다.
2. **Python: Select Interpreter**를 실행합니다.
3. 목록에서 프로젝트 폴더 아래의 `.venv` Python을 선택합니다.
   - 예: `.venv\Scripts\python.exe`
4. 노트북 파일을 열었다면 오른쪽 위 커널 선택 메뉴에서도 같은 환경을 선택합니다.

정상 연결 여부는 VS Code 터미널에서 아래 명령으로 확인합니다.

```powershell
python -c "import sys; print(sys.executable)"
```

출력 경로에 `.venv\Scripts\python.exe`가 포함되어 있으면 현재 프로젝트의 uv 가상환경을 사용 중입니다.

## 10. `.env` 파일 준비

CrewAI 실습에서는 OpenAI API 키를 `.env` 파일에 저장하고 `python-dotenv`로 불러옵니다. `03_crewai` 폴더 안에 `.env` 파일을 만들고 아래 형식으로 작성합니다.

```text
OPENAI_API_KEY=여기에_본인의_API_KEY를_입력
SERPER_API_KEY=웹검색_실습을_한다면_여기에_SERPER_API_KEY를_입력
```

API 키가 포함된 `.env` 파일은 외부에 공유하거나 GitHub에 업로드하지 않도록 주의합니다.

## 11. 노트북 실행 시 주의사항

Jupyter Notebook이나 VS Code Notebook에서는 이미 비동기 이벤트 루프가 실행 중일 수 있습니다. 최신 CrewAI에서 `crew.kickoff()` 실행 중 이벤트 루프 관련 오류가 발생하면 노트북에서는 아래처럼 async 버전을 사용합니다.

```python
result = await crew.kickoff_async()
print(result)
```

터미널에서 `.py` 파일로 실행할 때는 기존처럼 아래 코드를 사용할 수 있습니다.

```python
result = crew.kickoff()
print(result)
```

## 12. 설치 문제 해결

### uv 캐시 권한 오류가 나는 경우

Windows 환경에서 uv 캐시 폴더 권한 문제로 설치가 실패하는 경우가 있습니다. 그럴 때는 현재 프로젝트 안에 임시 캐시 폴더를 지정한 뒤 다시 설치합니다.

```powershell
$env:UV_CACHE_DIR = "$PWD\.uv-cache"
uv pip install -U python-dotenv notebook ipykernel "crewai[tools]"
```

### CrewAI import 중 opentelemetry 오류가 나는 경우

기존 가상환경에 여러 버전의 패키지가 섞이면 `opentelemetry` 관련 import 오류가 날 수 있습니다. 가장 깔끔한 해결 방법은 `.venv`를 새로 만들고 다시 설치하는 것입니다.

```powershell
deactivate
Remove-Item -LiteralPath .venv -Recurse -Force
uv venv --python 3.12
.venv\Scripts\activate
uv pip install -U python-dotenv notebook ipykernel "crewai[tools]"
```

기존 환경을 유지해야 한다면 관련 패키지를 같은 버전으로 맞춰 재설치합니다.

```powershell
uv pip install --reinstall --upgrade `
  "crewai[tools]" `
  opentelemetry-api `
  opentelemetry-sdk `
  opentelemetry-proto `
  opentelemetry-exporter-otlp-proto-common `
  opentelemetry-exporter-otlp-proto-http
```

설치 후에는 노트북 커널을 반드시 다시 시작합니다.
